Co je Kyllene

Hermes je skvělý agent: pamatuje si, učí se nové dovednosti a pracuje pro vás nonstop. Většinou se s ním ale potkáváte v terminálu, jednu konverzaci po druhé. Kyllene z Hermesu dělá místo, kde žije vaše práce.

Každý projekt má svůj domov s konverzacemi, soubory, tasklisty, nástěnkou Kanban a gitem. Můžete mít víc konverzací vedle sebe, předat úkol agentovi a vrátit se, až bude hotový, vidět, kolik který den stál, a spravovat celý Hermes bez úprav konfiguračních souborů.

Kyllene mluví s vaším stávajícím Hermesem, takže konverzace, paměť, skilly i profily jsou společné: co začnete v Kyllene, dokončíte v terminálu, a naopak.

Když něco chybí, doplníte si to: widgety ukážou na obrazovce cokoli a Hermes vám je umí napsat.

Kyllene je hora v Arkádii, kde se narodil Hermes. Proto podtitul „home of Hermes“.

Snímky

Kliknutím otevřete v plné velikosti. Všechna data na nich jsou vymyšlená.

Co je potřeba

  • Linux x86_64. Otestováno na Manjaru, Ubuntu 22.04 a 24.04 a Fedoře (GNOME, Wayland). Stejný AppImage běží i na jiných současných distribucích.
  • Nebo Windows 10/11 x64 (beta): viz Windows. macOS je v plánu.
  • FUSE pro spouštění AppImage (fusermount3 nebo fusermount). Desktopové instalace ho mají; instalátor to zkontroluje, a když chybí, napíše příkaz k instalaci pro vaši distribuci.
  • Asi 100 MB pro Kyllene a dalších asi 2,7 GB, pokud ještě nemáte Hermes.
  • Účet nebo API klíč k modelu (třeba Claude, ChatGPT, OpenRouter). Kyllene vlastní účet nemá a používá to, co má váš Hermes.
Hermes Agent předem instalovat nemusíte. Když chybí, Kyllene při prvním spuštění ukáže Chybí Hermes Agent a nainstaluje ho jedním tlačítkem (oficiální instalátor, bez sudo, do ~/.hermes, pár minut; potřebuje git a curl; když je distribuce nemá, nainstalujte je předem, např. sudo apt install git curl). Hermes už máte? Kyllene použije ten váš.

Instalace

Jeden řádek v terminálu. Bez sudo, všechno jde do vaší domovské složky.

  1. Spusťte instalátor: 
    curl -fsSL https://raw.githubusercontent.com/cpoint-eu/kyllene-releases/main/install.sh | bash
    Stáhne nejnovější AppImage do ~/.local/bin/Kyllene.AppImage, přidá Kyllene i s ikonou do menu aplikací, zkontroluje FUSE a skončí řádkem Done.
  2. Spusťte Kyllene z menu aplikací.
  3. Ještě nemáte Hermes? Klikněte na Instalovat Hermes Agent. Okno ukazuje jednotlivé kroky i stahování; po dokončení se Kyllene připojí sama, bez restartu.
  4. Připojte model. Čerstvý Hermes žádný nemá: v pruhu Hermes nemá připojený žádný model. klikněte na Připojit model a přihlaste se k poskytovateli nebo zadejte API klíč. První připojený poskytovatel se zároveň stane hlavním modelem.
  5. Začněte konverzaci. Hotovo. Diktování si jednou řekne o stažení modelu pro přepis řeči (menší je rychlejší).

Rozhraní se řídí jazykem systému; přepnete ho ikonou zeměkoule (CS / EN) ve spodní liště.

Bez instalátoru: stáhnout AppImage ručně

Stáhněte Kyllene_<verze>_amd64.AppImage tlačítkem níž (nebo z posledního vydání), povolte spouštění a spusťte:

Stáhnout AppImage

chmod +x ~/Stažené/Kyllene_*_amd64.AppImage
~/Stažené/Kyllene_*_amd64.AppImage

Položku v menu pro už stažený soubor přidá instalátor:

curl -fsSL https://raw.githubusercontent.com/cpoint-eu/kyllene-releases/main/install.sh | bash -s -- --appimage ~/Stažené/Kyllene_0.0.1-beta_amd64.AppImage

Složka se stahováním se může jmenovat i ~/Downloads.

Jako systémový balíček: .deb (Ubuntu, Debian, Mint) nebo .rpm (Fedora)

Vydání novější než 0.0.3-beta jsou i jako .deb a .rpm. Používají WebKit a GStreamer z vašeho systému a jsou menší než AppImage. Stáhněte ten pro váš systém z posledního vydání a nainstalujte:

sudo apt install ./Kyllene_*_amd64.deb
sudo dnf install ./Kyllene-*.x86_64.rpm

.rpm je podepsaný. Aby ho Kyllene mohla aktualizovat, jednou naimportujte klíč Kyllene:

sudo rpm --import https://raw.githubusercontent.com/cpoint-eu/kyllene-releases/main/kyllene-rpm-key.asc

Kyllene balíček aktualizuje sama; aktualizace si řekne o vaše heslo (práva správce). Odinstalace sudo apt remove kyllene nebo sudo dnf remove kyllene (data zůstanou). Používejte buď balíček, nebo AppImage, ne obojí.

Windows (beta)

Kyllene pro Windows 10 a 11 (x64) je novinka: stejná aplikace, jako instalátor .msi.

Stáhnout pro Windows (.msi)

  1. Stáhněte Kyllene_<verze>_x64_en-US.msi tlačítkem výš (nebo z posledního vydání).
  2. Dvakrát na něj klikněte. Kyllene se instaluje pro všechny uživatele počítače, proto si Windows řeknou o souhlas správce.
  3. Systém Windows ochránil váš počítač? Instalátor zatím není podepsaný, takže SmartScreen může varovat. Klikněte na Další informace → Přesto spustit (v anglických Windows More info → Run anyway).
  4. Spusťte Kyllene z nabídky Start. Ještě nemáte Hermes? Klikněte na Instalovat Hermes Agent: oficiální instalátor Hermesu dá všechno do %LOCALAPPDATA%\hermes bez práv správce a přinese si vlastní Git i Python (nejvýš asi 15 minut).
  5. Připojte model a začněte konverzaci, stejně jako na Linuxu.
  • Aktualizace přicházejí z aplikace (Nápověda › Zkontrolovat aktualizace): Windows si řeknou o souhlas správce, pak se Kyllene zavře, aktualizuje a sama znovu spustí.
  • Odinstalace ve Windows v Nastavení › Aplikace › Kyllene. Hermes v %LOCALAPPDATA%\hermes a vaše data v %APPDATA%\kyllene zůstanou; tyto složky smažte sami, jen když chcete pryč úplně všechno.
Omezení bety. Automatická kontrola po aktualizaci Hermesu (funguje pořád všechno?) zatím běží jen na Linuxu. Diktování, kódovací agenti, synchronizace, maskot a Kanban jsou na Windows méně otestované. Když něco nefunguje, nahlaste to i s verzí Windows a logy ze složky %APPDATA%\kyllene\logs.

Aktualizace

Kyllene se aktualizuje sama. Instalátor znovu pouštět nemusíte.

  • Novou verzi hledá při startu a pak jednou denně. Když vyjde, ukáže okno s přehledem Co je nového a tlačítky Aktualizovat a restartovat, Později (zeptá se zítra) a Přeskočit tuto verzi.
  • Ručně: Nastavení › O aplikaci › Zkontrolovat aktualizace, nebo Ctrl+K a Zkontrolovat aktualizace.
  • Rozjeté konverzace běží v Hermesu dál; po restartu se k nim Kyllene znovu připojí.
  • Každé vydání je podepsané a svázané s verzemi Hermesu, se kterými bylo otestované. Když je váš Hermes na novou Kyllene moc starý, okno nabídne nejdřív Aktualizovat Hermes (restartuje se tím gateway Hermesu a přeruší rozjeté konverzace, nechte je nejdřív doběhnout).
  • Když Hermes aktualizujete sami, Kyllene si sama ověří, že všechno, co používá, pořád funguje, a řekne vám, kdyby se něco rozbilo.

Kontrola aktualizací je jediné, co Kyllene sama stahuje z internetu: statický soubor v repozitáři vydání. Nic o vás se neodesílá.

Odinstalace

curl -fsSL https://raw.githubusercontent.com/cpoint-eu/kyllene-releases/main/install.sh | bash -s -- --uninstall

Odstraní aplikaci, její položku v menu a ikonu. Vaše data zůstanou, takže pozdější instalace naváže, kde jste skončili.

Smazat úplně všechno včetně dat

Nastavení, rozložení a data Kyllene:

rm -rf ~/.local/share/kyllene ~/.local/share/eu.cpoint.kyllene ~/.config/eu.cpoint.kyllene ~/.cache/kyllene ~/.cache/eu.cpoint.kyllene

Hermes Agent se všemi konverzacemi, pamětí, skilly a klíči je v ~/.hermes. Smažte ho, jen když Hermes nepoužíváte nikde jinde (terminál, Discord…):

rm -rf ~/.hermes ~/.local/bin/hermes

Složek vašich projektů se odinstalace nikdy nedotkne. Pokud jste zapnuli synchronizaci, synchronizovaná kopie zůstane ve vašem repozitáři na GitHubu nebo na cloudovém disku.

Řešení potíží

Hlášky instalátoru jsou anglicky, proto je tu uvádíme v původním znění.

PotížCo udělat
Instalátor skončí hláškou FUSE is missing., nebo AppImage hlásí No suitable fusermount binary found on the $PATH Nainstalujte FUSE a pusťte instalátor znovu: sudo apt install fuse3 (Debian, Ubuntu), sudo dnf install fuse3 (Fedora) nebo sudo pacman -S fuse3 (Manjaro, Arch).
Instalátor upozorní libGLESv2.so.2 (OpenGL ES) was not found, nebo se Kyllene hned po spuštění zavře s hláškou Couldn't open libGLESv2.so.2 Nainstalujte OpenGL ES: sudo apt install libgles2 (Debian, Ubuntu), sudo dnf install libglvnd-gles (Fedora) nebo sudo pacman -S libglvnd (Manjaro, Arch). Desktopové instalace ho už mají.
/dev/fuse is missing (v kontejneru nebo ve virtuálu bez FUSE) Spouštějte Kyllene jako ~/.local/bin/Kyllene.AppImage --appimage-extract-and-run.
Okno zůstane prázdné, bílé nebo černé (často s grafikou NVIDIA) Spusťte ho jednou z terminálu s obejitím GPU ve WebKitu: 
WEBKIT_DISABLE_DMABUF_RENDERER=1 ~/.local/bin/Kyllene.AppImage
Když je pořád prázdné, zkuste místo toho WEBKIT_DISABLE_COMPOSITING_MODE=1. V obou případech prosím nahlaste svou grafickou kartu, ovladač a prostředí (GNOME/KDE, Wayland/X11), ať se to dá opravit pro všechny.
Kyllene není v menu aplikací Pusťte instalátor znovu; přidá položku ~/.local/share/applications/kyllene.desktop. Některá prostředí ji ukážou až po odhlášení a přihlášení.
Instalátor hlásí … belongs to another Kyllene install (built from source?) Už máte Kyllene sestavenou ze zdrojáků. Instalátor s bash -s -- --force pusťte, jen když ji chcete nahradit.
Hermes se nepodařilo spustit Ověřte, že Hermes funguje v terminálu (hermes, případně ~/.local/bin/hermes), a Kyllene restartujte. Podrobnosti na té obrazovce říkají, co selhalo.
Instalace Hermesu tlačítkem selže Okno ukáže krok, který selhal, i výpis instalátoru. Většinou jde o síť nebo místo na disku (potřebuje asi 2,7 GB): napravte to a klikněte na instalaci znovu.
Konverzace začne, ale odpověď nepřijde Hermes ještě nemá model: v pruhu Hermes nemá připojený žádný model. klikněte na Připojit model, nebo v terminálu spusťte hermes setup.
Diktování napoprvé nic neudělá Jednou potřebuje model pro přepis řeči: Kyllene nabídne jeho stažení. Později ho změníte v Nastavení › Přepis řeči.
Po aktualizaci Hermesu se něco rozbilo Kyllene vám řekne, co nefunguje. Než vyjde nová Kyllene, můžete Hermes vrátit na verzi uvedenou v popisu vydání („Tested with Hermes Agent …“).
Okno ukazuje jen horní lištu na tmavém pozadí Část appky spadla. Prosím nahlaste to a přiložte ~/.local/share/kyllene/crash-log.json.
Windows: Systém Windows ochránil váš počítač při otevření .msi SmartScreen varuje, protože instalátor zatím není podepsaný. Klikněte na Další informace → Přesto spustit. Stahujte ho jen z posledního vydání.
Windows: instalace nebo aktualizace chce souhlas správce Schválně: Kyllene se instaluje pro všechny uživatele počítače. Když souhlas odmítnete, aktualizace se zruší a zůstane nainstalovaná dosavadní verze.
Kde jsou moje data? Linux: Kyllene v ~/.local/share/kyllene, Hermes v ~/.hermes. Windows: Kyllene v %APPDATA%\kyllene (logy v %APPDATA%\kyllene\logs), Hermes v %LOCALAPPDATA%\hermes. Odinstalace je nikdy nesmaže.

Pořád to nejde? Založte issue s distribucí, prostředím, verzí Kyllene (Nastavení › O aplikaci) a tím, co vidíte. Psát můžete česky.
