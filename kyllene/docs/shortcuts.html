Keyboard shortcuts

The same list is in the app: Settings › Shortcuts. Ctrl+K opens the command palette, where every command also shows its shortcut.

Everywhere

Keys What it does
Ctrl+K Command palette and search everywhere: conversations, projects, commands, message content, project files, Kanban, tasklists and memory
Ctrl+N or Ctrl+T New conversation (in the project or agent you are in)
Ctrl+W Close the active conversation
Ctrl+Tab / Ctrl+Shift+Tab Next / previous conversation
Ctrl+Shift+PageUp / PageDown Move the conversation tab one place left / right
Ctrl+1 … Ctrl+8 Go to conversation 1–8 (tab order)
Ctrl+9 Go to the last conversation
Ctrl+B Hide the left menu / pin it again
Ctrl+. Hide / pin the right panel (widgets, opened file)
Esc Finish editing the layout (in the layout editor)
Ctrl+, Open Settings
Ctrl+Shift+H Hermes management (skills, cron jobs…)
Ctrl+Shift+N Notifications (bell)
Ctrl+L Put the cursor into the message field
Ctrl+` Switch the conversation between chat and the real Hermes terminal
Ctrl+Shift+F9 Activity: toggle the panel
Ctrl+Shift+F Focus mode on the current project ⇄ the whole app
Ctrl+Shift+O Project outputs (right panel) on / off
Ctrl+Shift+D Bookmarks window

Top menu (Work / Agents / Hermes)

Keys What it does
← → Move between the menus (opens the neighbour when one is open)
Enter or ↓ Open the menu and go to its first item; ↑ ↓ move inside
Esc Close the menu and return to its button

Writing a message

Keys What it does
Enter Send the message
Shift+Enter New line
Esc Stop the running answer (or stop reading aloud)
/ Hermes commands and skills (suggestions)
/later Continue this conversation at a set time (/later <when>; also palette › Continue later…)
Tab or ↑ ↓ Accept / move in the suggestions
Ctrl+V Paste an image from the clipboard as an attachment
Ctrl+Space (hold) Dictate: release to transcribe the speech into the message (changeable)
Ctrl+Shift+E Tidy up the message text (selection, last dictation or the whole draft)

Prompt template form

Keys What it does
Enter Next field (Shift+Enter = new line; on the last field runs the template)
Ctrl+Enter Run from any field

Text editor (tasklists)

Keys What it does
Enter Save, continue with the next block (empty = stop)
Shift+Enter New line inside the block
Esc Cancel the change
Ctrl+B / Ctrl+I / Ctrl+E Bold / italic / code
Ctrl+K Link
Ctrl+Shift+X Strikethrough
Tab / Shift+Tab Indent / outdent a list item or task
Backspace In an empty block: delete it

Diagram (canvas)

Keys What it does
Delete or Backspace Delete the selected nodes / edges
Double-click Rename a node or an edge; on the empty area: new node
Enter or Esc Save the name (Shift+Enter = new line), Esc = cancel

Activity panel edge (focused)

Keys What it does
← → Wider / narrower panel (Shift = bigger steps)
Home or End Narrowest / widest panel
Double-click Back to the default width

Kanban

Keys What it does
Ctrl+Shift+R Open the last run of the open card
Ctrl+K › Process a card with a Hermes agent… Pick a card, its Process with … menu opens
Ctrl+K › Review a card with … Pick a finished card, its Review with … menu opens
↑ ↓ or Enter In the card picker: move and open

Command palette

Keys What it does
↑ ↓ Move in the results
Enter Run / open the selected item
/ Switch to Hermes commands and skills
Esc Close

System-wide and widgets

  • Quick capture from any app: off until you switch it on in Settings › Quick capture (suggested Ctrl+Alt+Space).
  • A widget can have its own shortcut: set it in the widget's ⋯ › Widget settings.
