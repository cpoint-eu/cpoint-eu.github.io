Troubleshooting

Problem What to do
The AppImage does not start: "No suitable fusermount binary found on the $PATH" Install FUSE: sudo pacman -S fuse3 (Manjaro, Arch), then start Kyllene again. The installer checks this for you.
Kyllene is not in the app menu Run the installer again; it adds the menu entry (~/.local/share/applications/kyllene.desktop).
The window stays empty or white Start it once with WEBKIT_DISABLE_DMABUF_RENDERER=1 ~/.local/bin/Kyllene.AppImage (if still empty, WEBKIT_DISABLE_COMPOSITING_MODE=1 instead) and report your GPU and desktop.
"Hermes could not be started" Check that Hermes works in a terminal (hermes), then restart Kyllene.
Conversations start but the model does not answer Hermes has no model yet: click Connect a model in the bar Hermes has no model connected. and sign in to a provider (the first one becomes the main model), or run hermes setup in a terminal.
Dictation does nothing on the first try Dictation needs a speech model once: Kyllene offers to download it (the smaller one dictates faster); change it later in Settings › Speech to text.
Kanban cards stay in Ready The Hermes gateway is not running; the board header says tasks will not run. Start it (hermes gateway) with Kanban dispatch enabled. See Kanban.
A widget from another computer does not run Its code waits for your approval on this computer: Sync between computers.
Something broke after a Hermes update Kyllene checks itself after every Hermes update and tells you what does not work; until a new Kyllene is out you can go back to the Hermes version it was tested with (named in the release notes and in Settings › About).
